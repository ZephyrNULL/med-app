HARDWARE IMPLEMENTATION
The ESP32 box uses 7 VL53L0X distance sensors (I2C 0x30-0x36, enabled one at a time via XSHUT), a DHT22 temperature/humidity sensor, a DS3231 RTC, a 20x4 LCD, 7 LEDs and a buzzer. On boot it initializes sensors, re-syncs the RTC if power was lost, then connects WiFi and MQTT. Every 500ms it reads all sensors, triggering LED/buzzer reminders once RTC time reaches a scheduled dose (within a catch-up window, so a slow sensor sweep never skips a dose). A distance over 90mm means the bay is empty; 3 consecutive such readings confirm the dose was taken (debounce). It publishes temperature/humidity every 30s and events immediately over MQTT.

SOFTWARE IMPLEMENTATION
The Flutter app starts Supabase auth and local notifications, then checks the session and loads role-based data (patient or caregiver). CareCubeRepository bridges MQTT and Supabase, updating live state and persisting to Postgres. Home shows dose progress, next dose and temperature/humidity. Medicine performs schedule CRUD over the six stored compartments (Day 1M/1A/1N, Day 2M/2A/2N — two days, morning/afternoon/night), republishing the full 6-slot array to the ESP32. Alerts show a live event feed; caregivers can remotely stop alarms. Profile shows box status and personal info. Supabase enforces row-level security.
